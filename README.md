## ✨ 简介

**学习桌面（StudyDesk）** 把学生日常需要的工具整合进一个精致的桌面应用：左侧 macOS 风格侧边栏导航，半透明毛玻璃卡片，明暗双主题与可定制强调色，配合系统通知、托盘常驻、全局热键与桌面浮窗，帮助你**专注学习、规划时间、养成习惯**。

> 学习数据全部保存在本地，无需登录即可使用；媒体资源（壁纸 / 铃声 / 音乐）支持本地导入与在线链接添加。
> 「自习室」是唯一联网的部分：连自建服务器 `study.lemon21.cn`，**不用注册账号**，昵称与一个匿名设备标识就是全部身份。

## 🎯 功能特性

### 📅 课表
- 周视图网格，**当前课程高亮**、今日列高亮
- 自定义作息时间段（节次起止时间随意调整）
- 点格子增删改课程：名称 / 教师 / 地点 / 颜色 / 星期 / 节次
- 课表 **JSON 导入 / 导出**

### 🔔 上下课铃声
- 到点按课表**自动响铃**（上课 / 下课不同铃声）
- 内置**真实校园铃声**：校园电铃「铃铃铃」、威斯敏斯特音乐钟声（合成，离线可用，已设为默认上/下课铃）
- 上课同时弹**系统通知**
- 铃声支持**在线搜索**（搜「上课铃声/下课铃声」）、本地文件或在线链接，音量可调

### 🍅 番茄钟 & 专注
- **三种计时方式**：倒计时（到点自动进入休息）/ 正计时（不设终点，学多久记多久）/ 不计时（不显示数字，只记开始与结束）
- **时长随手改**：15 / 25 / 45 / 60 / 90 分钟预设，也能填任意分钟数；选过的方式与时长下次自动沿用
- 工作 / 短休 / 长休循环，时长与长休间隔可配，可自动开始下一阶段
- 圆环进度 + 大号倒计时，完成自动计入统计并提示音
- **计时以时间戳为准**：合上电脑再打开，走过的时间照算不漂移；每一段专注都会留下明细（实际时长、方式、绑定任务、是否走完）
- **锁屏壁纸专注**：专注时自动全屏置顶大字倒计时，防止分心（Esc 暂停退出）
- **4 种锁屏时钟样式**：极简 / 翻页钟 / 像素 LED / 呼吸光
- **呼出全屏时钟弹窗**：番茄钟页一键呼出全屏时钟（复用所选样式），随时进入专注视图

### 🌳 专注花园（游戏化成长）
- 每完成一个番茄 **+金币并种下一棵树**：新树以**幼苗 🌱 落地**，被后续专注**浇灌逐步长成大树**
- **每日任务**：每天 0 点刷新 3 个任务（完成番茄 / 累计分钟 / 种树），完成后手动领取金币奖励
- **装饰商店**：石灯笼 / 长椅 / 风铃 / 莲花池 / 喷泉 / 帐篷，买下后自由摆放到任意空地块、可收回重摆
- **指定种植位置**：点击空地块即可指定下一棵树落在哪里，把花园布置成自己的样子
- **金树掉落**：每次专注小概率种出**发光金树**并获得额外金币
- **树种图鉴** + **成就墙**（10 项）：收集松树 / 樱花 / 椰子 / 枫树 / 圣诞树，记录初遇时间
- 连续专注天数有金币加成，等级随累计专注时长成长

### 🧑‍🤝‍🧑 联网自习室（一起自习，但没有聊天框）
- **自习室是长期的，房间是今天的**：加入自习室是成员身份，关掉应用也还在；进出房间只是「今天来不来学」，离开房间不会退出自习室
- **开一间自己的**：起名字、写简介、定集体目标，拿到 8 位加入码发给同学；主人可随时改资料，也可以解散
- **公开大厅**：能看到此刻真的有人在学的房间，先进去学一会儿，觉得合适再点加入
- **日 / 周 / 月排行榜**：房内成员按该时间段的专注时长排名，自己的名次一直显示在顶部
- **真实的坚持天数**：连续专注天数与累计专注天数都按实际记录算，不是从注册日往下数
- **起床 / 睡觉打卡**：每天各记一次，以第一次为准，时间会显示在成员名片上
- **许愿墙**：写下一句给自己的话，同学都能看到；链接、联系方式、长串数字发不出去，看到不合适的内容可举报，攒够自动隐藏
- **看得见彼此在专注**：每位成员是自己的猫，专注时低头写字，实时显示谁在座、谁在专注
- **预设加油动作**：💪👏⭐🌸🍵💗✨🚀 八种固定动作，可对全体或某位同学发送，对方猫头顶冒气泡
- **没有聊天、没有私信、没有图片**：协议里根本不存在自由文本消息，昵称 / 房间名 / 简介 / 愿望都会自动拦截链接、微信/QQ 号、手机号与推广词，**从机制上杜绝广告**
- **不用注册**：昵称只是展示名，身份靠本机生成的匿名标识，服务端不存手机号、邮箱或任何可识别到人的信息

> 服务端是自建的（`wss://study.lemon21.cn/ws`），源码在 `server/`，数据落在服务器上的一个 SQLite 文件里。

### 🌬️ 深呼吸 / 冥想
- 课间跟随圆环做 **4-4-6 节律呼吸**（吸气 → 屏息 → 呼气），带阶段提示与组数计数，快速放松回到专注

### ✅ 备忘录中心（任务 / 备忘 / 灵感）
- 三种记录类型：**任务 / 备忘 / 灵感**，智能列表：**今天 / 计划 / 备忘录 / 全部 / 已完成**（带计数）
- **置顶**重点条目、优先级彩色旗标、截止日期（今天 / 明天 / 下周快捷芯片）、标签、子任务进度条
- **到点提醒**：设置提醒时间后**弹系统通知**（应用在托盘后台也能提醒）
- **绑定番茄钟**：任务一键「开始专注」，完成的番茄自动累计到该任务（进度 🍅 2/4 实时可见）
- **重复任务**（每天 / 每周，完成自动生成下一次）、已完成按日期分组回顾、删除有确认弹窗

### ⏳ 倒数日
- 考试 / 截止日 / 重要日子倒计时，按剩余天数排序
- 每张卡片可设**自定义背景图**（本地 / 在线 / 链接）
- 倒数日卡片可一键创建为独立桌面摆件
- 仪表盘底部显示最近一个「距 X 还有 N 天」

### 🖥️ 桌面摆件
- 支持把**倒数日 / 今日课表 / 备忘录**创建为独立桌面卡片，内容随原始数据同步更新
- 小 / 中 / 大三种尺寸：小卡突出核心信息，大卡展示更多课程或备注细节
- 每个摆件可独立设置**背景图片、底色、字体、文字色、强调色、图片遮罩与不透明度**
- 支持固定显示和开机自动启动；摆件保持桌面普通窗口层级，不会遮挡其他应用
- 卡片自带锁定开关；锁定后除小锁外完全穿透鼠标，避免误拖动，也可随时原位解锁
- 备忘录摆件集中展示全部未完成的备忘与灵感，可直接快捷记录；倒数日可在卡片上快速切换
- 内置马善政手写体、站酷小薇体、站酷庆科黄油体等艺术字体，无需联网加载
- 桌面摆件管理页统一负责显示、隐藏、编辑和移除，不删除原始课表、倒数日或备忘录数据

### 📚 学习资料库（书架升级版）
- 添加 PDF / 电子书 / Word / PPT / Excel / **JPG、PNG、WebP 等图片**，按**分类 / 状态 / 收藏 / 标签**整理
- 图片资料直接显示真实缩略图，双击仍使用系统默认程序打开
- **页码进度**：填「当前页 / 总页数」自动换算百分比，或直接拖进度条
- **阅读计时**：点「计时阅读」开始，结束自动落账到**阅读记录**，累计阅读时长一目了然
- **读书笔记**：每本书可记多条摘录 / 想法（支持页码标注），全局搜索也能搜到笔记内容
- **继续阅读**：顶部横幅直达最近在读的书
- **文件丢失检测**：源文件被移动 / 删除会标红提示，**一键重新定位**
- 双击卡片用**系统默认程序打开**，打开次数 / 最近打开自动统计

### 🎵 背景音乐
- **在线曲库**：进入即自动拉取轻音乐列表，点条目即播放、＋收藏入库（在线源为公开音乐接口）
- **一键导入网易云 / QQ 音乐歌单**：粘贴歌单分享链接自动解析曲目（基于 Meting 式聚合接口，接口地址可在设置更换为自建以提升稳定性）
- **在线搜索** + 关键词自定义，本地导入 / 链接添加
- 列表 / 单曲 / 不循环，音量记忆，跨页面持续播放
- > 提示：在线源受版权限制，部分歌曲可能只能试听或无法播放

### 📊 专注统计
- **总览**：累计专注小时、累计番茄、真实专注天数与连续天数、今天的进度
- **趋势图**：近 7 天 / 近 30 天，可按分钟或番茄个数看；日均只按真正学过的天算，不被休息日稀释
- **时段分布**：一天 24 小时的专注分布，告诉你几点最坐得住
- **时间花在哪**：按番茄钟绑定的任务累计排行
- **最近的专注**：每一段的开始时间、时长、计时方式、绑定任务与是否走完

### 💧 喝水 & 🧍 健康提醒
- 喝水提醒（可配间隔 + 每日目标），仪表盘「喝一杯」计数与进度
- 久坐提醒、护眼 20-20-20

### 🪟 系统集成 & 个性化
- macOS 风外壳 + 右上角窗口控制；**桌面浮窗**（置顶可拖：时钟 + 下节课 + 番茄迷你计时）+ **全屏时钟弹窗**
- **关闭即最小化到托盘后台常驻**（启动即建托盘，点右上角关闭不退出，托盘右键「退出」才真正退出）
- 系统托盘常驻、开机自启、全局热键；侧边栏实时显示**番茄迷你计时**，随点随回
- **全局搜索 Ctrl+K**（页面 / 课程 / 备忘 / 资料 / 倒数日）
- 明暗主题 + 6 种预设强调色 + **任意自定义强调色**（取色器随便挑）+ **自定义应用背景图**（界面透明度 0–100% 可调）
- **全局轻提示 / 确认弹窗**：操作有即时反馈，删除等危险操作有二次确认
- **数据备份 / 恢复**（一键导出 / 导入全部 JSON）
- **自动更新**（基于 GitHub Release：**检测到新版本应用内弹窗提醒** + 下载进度条 + 下载完成弹窗与系统通知 + 一键重启安装）

## 🆕 版本历史

### v0.6.1（最新）
- **修复锁屏专注可能叠出第二个全屏窗、而且再也关不掉**：`close()` 是异步的，关闭的瞬间窗口还活着，此时若又要开锁屏就会同时存在两个；更糟的是旧窗口随后触发 `closed`，会把已经指向新窗口的引用清成 null，新窗口从此谁也关不掉。现在改为同步销毁并按窗口身份校验回调
- **全局快捷键注册失败不再沉默**：被别的程序占用或组合键写法不合法时，设置页会在对应输入框下方直接说明原因，不用再靠「按了没反应」去猜
- **记住主窗口的大小和位置**：下次打开还在原地；外接屏拔掉后会自动收回主屏中央，不会开在看不见的地方

## 🤝 资源约定

壁纸、铃声、音乐等媒体可在对应页面「本地 / 从链接 / 在线搜索 / 导入歌单」获取；在线资源会下载到本地后离线使用。内置默认：合成校园铃声（电铃 / 音乐钟声）、提示音兜底、渐变锁屏背景。

> **音乐 / 歌单接口**：在线搜索基于 iTunes 公共接口（合法、免 key，为 30s 试听片段）；网易云 / QQ 歌单导入基于 [Meting](https://github.com/metowolf/meting) 式聚合接口，默认使用公共实例（可能不稳定），可在「设置 → 音乐接口」填入自建 [Meting-API](https://github.com/metowolf/Meting-API) / [NeteaseCloudMusicApi Enhanced](https://github.com/NeteaseCloudMusicApiEnhanced/api-enhanced) 地址以提升稳定性与解锁能力。部分歌曲受版权限制可能仅试听或无法播放。
